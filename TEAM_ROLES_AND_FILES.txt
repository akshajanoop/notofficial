================================================================================
CINERESERVE: MOVIE TICKET BOOKING SYSTEM
4-MEMBER TEAM PROJECT WORKLOAD & FILE ASSIGNMENT BREAKDOWN
(INCLUDING ADMIN PORTAL FOR INSERTING MOVIES, THEATRES & SHOWS)
================================================================================

PROJECT SUMMARY:
A 4-tier Movie Ticket Booking System built with Java 17, Spring Boot 3,
Spring MVC, Direct JDBC (JdbcTemplate), H2/MySQL, and Bootstrap 5.3.
Includes full Admin Access at "/admin" to insert and manage movies, theatres,
and showtimes.

--------------------------------------------------------------------------------
OVERVIEW MATRIX
--------------------------------------------------------------------------------
Member 1: Database & Project Setup (10 files) - Easy
Member 2: Seat/Booking Models & All Repositories/Queries (14 files) - Easy/Medium
Member 3: Business Logic, Math & Rules (6 files) - Hardest (Math, Algorithms, Concurrency)
Member 4: Webpages, Admin Portal & Connectors (19 files) - Medium (HTML, UI, Controllers)

================================================================================
MEMBER 1: DATABASE & PROJECT SETUP
================================================================================
Role:
Creates the database tables, defines relationships (foreign keys, cascading deletes),
inserts sample seed data, handles application configuration and project dependencies,
and writes the initial core Java domain models.

Assigned Files (10 files):
1.  sql/schema.sql
    - 10 SQL tables with primary keys, foreign keys, and indexes.
    - Configured ON DELETE CASCADE for shows/seats when admin deletes a movie or theatre.
2.  sql/data.sql

3.  src/main/resources/application.properties

4.  pom.xml
    - Maven dependencies (Spring Boot, Thymeleaf, JDBC, MySQL Connector, H2).
5.  src/main/java/com/moviebooking/MovieBookingApplication.java
    - Main entry point that starts the Spring Boot application and scheduler.
6.  src/main/java/com/moviebooking/config/DatabaseConfig.java
    - Spring configuration setting up the JdbcTemplate bean.
7.  src/main/java/com/moviebooking/model/User.java
    - Java class: userId, name, email, password, login() helper method.
8.  src/main/java/com/moviebooking/model/Movie.java
    - Java class: movieId, title, genre, rating, duration, posterUrl, director, cast.
9.  src/main/java/com/moviebooking/model/Theatre.java
    - Java class: theatreId, name, location, city, latitude, longitude.
10. src/main/java/com/moviebooking/model/Show.java
    - Java class: showId, movieId, theatreId, showTime, getShowDate(), getFormattedTime().

Admin Portal Contribution:
- Designed the relational tables with auto-increment IDs and foreign keys so newly
  inserted movies, theatres, and shows automatically link together properly.

================================================================================
Role:
Creates the advanced seat, booking, auction, and credit model classes, and writes
all repository classes using Spring's JdbcTemplate to run SQL queries (including
admin INSERT and DELETE queries) and map database rows into Java objects using RowMappers.

Assigned Files (14 files):

3.  src/main/java/com/moviebooking/model/SeatStatus.java
    - Java Enum: AVAILABLE, LOCKED, RESERVED.
4.  src/main/java/com/moviebooking/model/Booking.java
    - Java class: bookingId, userId, showId, totalAmount, status.
5.  src/main/java/com/moviebooking/model/Auction.java
    - Java class: auctionId, seatId, currentBid, highestBidderId, endTime.
6.  src/main/java/com/moviebooking/model/Credit.java
    - Java class: userId, balance, earn(), redeem().
7.  src/main/java/com/moviebooking/model/CreditTransaction.java
    - Java class: transactionId, amount, transactionType, balanceAfter.
8.  src/main/java/com/moviebooking/repository/UserRepository.java
    - SQL queries for users (findByEmail, findById, save, existsByEmail).
9.  src/main/java/com/moviebooking/repository/MovieRepository.java

14. src/main/java/com/moviebooking/repository/CreditRepository.java

Admin Portal Contribution:

================================================================================
MEMBER 3: BUSINESS LOGIC, MATH & RULES (SERVICES)
================================================================================
Role:
Writes the business rules, calculations, and real-time features. Handles atomic
concurrency checks, the 10% loyalty cashback formula, the Haversine distance
algorithm, and the background auction timer.

Assigned Files (6 files):
1.  src/main/java/com/moviebooking/service/BookingService.java
    - Rules: checks seat availability, locks seats, calculates subtotal, confirms booking.
2.  src/main/java/com/moviebooking/service/CreditService.java
    - Math: calculates 10% cashback (Points = Amount * 0.10) and applies discount at checkout.
3.  src/main/java/com/moviebooking/service/RecommendationService.java
    - Math: Great-Circle Haversine formula to compute exact km distance to theatres.
4.  src/main/java/com/moviebooking/service/AuctionService.java
    - Bidding rules: ensures new bid > current highest bid, marks winner on expiration.
5.  src/main/java/com/moviebooking/scheduler/AuctionScheduler.java
    - Background daemon: runs every 10 seconds to auto-close expired auctions.
6.  src/main/java/com/moviebooking/service/MovieSyncService.java
    - Startup logic: fetches official movie posters and IMDb ratings.

Admin Portal Contribution:
- Built the automated 30-seat generator (populateDefaultSeatsIfEmpty in SeatRepository)
  which triggers when an admin schedules a show, instantly generating Standard,
  Premium, and VIP Recliner seats ready for booking.

================================================================================
HOW ALL 4 MEMBERS CONNECT TOGETHER FOR ADMIN ACCESS
================================================================================
Admin enters Movie/Theatre details on "/admin" page (Member 4 - admin.html)
        |
        v
AdminController receives the POST request (Member 4 - AdminController.java)
        |
        v
Calls MovieRepository / TheatreRepository to INSERT (Member 2 - Repositories)
        |
        v
Calls SeatRepository to generate 30 seats if show (Member 3 - Logic / Seats)
        |
        v
Saves row into SQL Database with auto-increment ID (Member 1 - SQL Schema)
        |
        v
Redirects to "/admin" with green "Success!" alert (Member 4 - UI)
